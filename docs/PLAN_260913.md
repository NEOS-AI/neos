### 3.1 멀티에이전트 / 동적 서브에이전트

**CC:** `AgentTool`(Task) → `runAgent` → **중첩 `query()` while**. 타입은 카탈로그(빌트인/프로젝트 md/플러그인/SDK JSON, last-wins). 모델이 런타임에 타입을 발명하지 않음. 외부 빌드에서 자식은 Agent를 못 씀(실효 depth 1). 부모는 park하지 않고, async면 `<task-notification>` 을 다음 루프에 넣음. worktree는 선택, 부모 cwd 불변. coordinator/team/fork는 별 제품.

**Hermes:** `delegate_task` → 자식 `AIAgent` 를 워커 스레드에서 **끝까지**. 기본 depth 1, orchestrator 기본 on, worktree 기본 off. 자식은 부모 툴을 넓히지 못함. 채널 키 미상속.

**iii:** 스펙만. `harness::spawn` = 새 세션 + 부모 park + join. 자식 allow ∩ 부모 allow. `max_depth` 3 / `max_children` 5. `expose: native` (작은 고정 셋) vs `agent_trigger` (거대 버스). 엔진 재작성은 비목표.

**NEOS 지금:** Approach C/M가 이미 맞는 쪽이다. 자식은 1-step, 부모 park/fold, 카탈로그 fail-closed explore\|implement, depth 0|1, fill-then-RR.

## 10. 스트림 G — 프롬프트 품질 / usable window / 모델 계약

이번 분석에서 티켓 표에 없던 **가장 큰 코딩 품질 구멍**. `NEOS_CODING.md` §5.4 가 이미 usable window를 요구한다.

### G1. Catalog usable window — CLOSED (P1)

- YAML에 `context_window`, 선택 `input_limit`, `thinking_budgets`.
- `usable = max(0, (input_limit ?? context_window − max_output) − reserved − thinking_budget)`.
- `reserved` 기본 `min(20000, 10% window)` — 훅/레슨/지시 주입이 창을 먹지 못하게.
- compact 트리거를 `DEFAULT_MAX_TRANSCRIPT_TOKENS = 80_000` 상수에서 **usable** 로 교체.
- cache_read/write/reasoning 을 compact·spend·`/cost` 에 반영. provider가 cost를 안 주면 카탈로그 가격으로 채움.
- 콜드/unknown 모델: request shaping 유지, picker만 숨김 (이미 카탈로그 극성).
- **파일:** `models.yaml`, `model_identity`, `neos/coding/model/base.py` `ModelLimits`, `durable.py` compact.
- **금지:** live catalog merge, 코딩 picker.

### G2. `previous_summary` 를 system에 — CLOSED

compact 요약은 user “Prior context summary”가 아니라 캐시 경계 **뒤** system `## Conversation summary`. 다음 compact가 `state.summary` 를 갱신. 페어 불변 유지. persist-then-ref 는 그대로.

### G3. 적응형 DenialEnvelope — CLOSED

`reason_code` 는 유지. 모델이 보는 `reason` 은 짧은 적응 문장. `rm -r` / `git reset --hard` 경고는 envelope `warnings` + reason. S-코드 금지.

### G4. Untrusted wrap on `web_fetch` — OPEN (P2)

결과 delimiter + closer 토큰 중화. Hermes 32자 skip을 정책으로 복사하지 않음. E6 prompt-on-content와 별개, 기본은 wrap만.

### G5. compact-safe `revealed_tools` — OPEN (P2)

CC `preCompactDiscoveredTools`. compact 후 이미 고른 툴 definition이 사라지지 않게.

### G6. Fold headroom 배선 — OPEN (P2)

`fold.py` 의 `parent_headroom_chars` 를 부모 마지막 `prompt_tokens` 잔여에서 넣는다. 정적 4k만 쓰지 않음.

### G7. 자식 native expose — OPEN (P2)

explore/implement 는 작은 고정 툴셋(이미 phase hide). 부모만 deferred/`search_tools`. 자식에게 거대 MCP 풀을 주지 않음. 자식은 부모 툴을 넓히지 못함.

### G8. Spawn pending timeout + cancel cascade — OPEN (P2)

죽은 자식이 부모 park/lease를 영원히 잡지 않음. `/stop` 은 이미 worktree discard. 여기에 timeout + 자식 트리 cancel.

### G9. 지시 파일 scan-and-block — OPEN (P3)

Hermes context-file 스캔. 기존 untrusted wrap **위**에 fail-closed 한 층. 프롬프트 박물관 복사 금지.

### G10. Effort 카탈로그 필드 — OPEN (P3)

`effort: {support, default, max?}`. 와이어 `output_config`. 프롬프트 형용사로 흉내 내지 않음. 모델 기본값을 디스크에 쓰지 않음. `/effort` (E8) 와 같은 계약.

### G11. Output style / per-agent model pin — OPEN (P3)

named overlay after boundary. 자식 `inherit` | role-alias | pin. family alias는 부모 exact pin에 sticky. 코딩 UI picker 아님.

### G12. 프롬프트 버전/평가 — OPEN (P3)
